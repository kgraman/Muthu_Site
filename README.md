## 🚀 How to Run & View Locally

You can open `index.html` directly in any web browser by double-clicking it, or run a lightweight local server:

### Using Python:
```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080` in your web browser.

---

## 🌐 Deploying to the Web

The website is 100% static, fast-loading, zero-dependency, and can be hosted for free on:
- **GitHub Pages**: Push this directory to a GitHub repository and turn on Pages in repository settings.
- **Vercel / Netlify**: Drag-and-drop the `Muthu_Site` folder into Netlify Drop or import the repository on Vercel.
- **Custom Domain**: Connect any custom domain such as `www.muthooraman.com` or `www.ramanmuthoo.com`.
